Three Operations for Memory

Simple API, powerful agent workflows

01

Store

Call store_thought after every action, decision, or discovery. Include content, type, topics, and people metadata.

02

Search

Call semantic_search before asking users to repeat. Find related thoughts by meaning.

03

Reflect

Periodically call reflect to consolidate insights and prune stale memories automatically.

Start in 30 Seconds

Zero config, just run

# One-line install (macOS / Linux) curl -fsSL https://raw.githubusercontent.com/asabya/picobrain/main/install | bash

# Run the server ./picobrain --db ~/.picobrain/brain.db --port 8080

# Add to Claude Desktop (claude_desktop_config.json)
{ "mcpServers": { "picobrain": { "command": "npx", "args": ["@modelcontextprotocol/server-streamable-http", "http://localhost:8080/mcp"] } } }

# Or add to OpenCode (opencode-config.json)
{ "picobrain": { "enabled": true, "type": "http", "url": "http://localhost:8080/mcp" } }

# From your agent, store a thought
{ "content": "Alice prefers PR descriptions under 50 words", "type": "person_preference", "topics": ["pr", "communication"], "people": ["Alice"] }

# Later, semantic search
"How does Alice like her PRs described?"
